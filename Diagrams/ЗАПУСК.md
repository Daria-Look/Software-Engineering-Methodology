# Подробная пошаговая инструкция, чтобы запустить сгенерированный HTML-отчет через локальный веб-сервер с помощью Python (Windows)

## Шаг 1. Найдите папку с отчетом

Откройте проводник Windows и перейдите в ту папку, куда вы сохранили результат экспорта HTML из Enterprise Architect.

## Шаг 2. Откройте командную строку в этой папке

## Шаг 3. Запустите локальный сервер

В открывшемся окне терминала введите следующую команду (если у вас установлен Python):

```bash
python -m http.server 8000
```

## Шаг 4. Откройте отчет в браузере

Введите в адресную строку следующую ссылку:

```text
http://localhost:8000
```

Перейдите по ссылке.
